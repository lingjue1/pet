# Changelog

## 0.1.1

- 首次发布到 npm：`cortico-world-pasture`。
- README 补充从 npm 安装与手动填包名的方式。

## 0.1.0

- 首个可安装版本：13 个牧场工具、自动巡视、每小时小日志。
- 每种动物 ≤2；4 星以下成年动物可清理，同种 2 只低星可全卖重刷。
- 槽位价格 2 倍询问、4 倍自动购买。
- 所有由扩展打开的商店/牧场界面在操作后自动关闭。
- World 页新增「牧场控制台」面板：状态卡、常用动作按钮、动物列表。
- `cursorRestore` 默认关闭；打开后喂食结束用 PowerShell 还原鼠标。
- 改为 TypeScript + vitest，补 `describe.json`、`test`、`typecheck`。
